CastMivo is an Android screen-casting application by Prem Creation, designed to mirror your Android phone screen to a compatible Android TV using supported wireless connections.

Bring your phone experience to the big screen!

✨ Features

- 📱 Phone to TV Casting – Mirror your Android phone screen to a compatible Android TV.
- 📶 Wi-Fi Connectivity – Connect devices using a supported Wi-Fi network.
- 🔥 Mobile Hotspot – Support for hotspot-based wireless connectivity.
- 📺 Big Screen Experience – Enjoy your mobile screen on a larger display.
- 🎯 Simple Interface – Easy-to-use connection controls.
- 🔒 User Permission Control – Screen capture requires user approval.

📡 Transfer Methods

- Wi-Fi Network
- Mobile Hotspot
- Wireless Screen Mirroring

Availability depends on the features supported by the installed app version and device compatibility.

🚀 How to Use

1. Install CastMivo on your Android phone.
2. Connect your phone and Android TV using a supported network.
3. Open CastMivo.
4. Follow the connection instructions.
5. Approve the screen-capture request.
6. Start screen casting.
